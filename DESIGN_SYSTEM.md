# Henima Design System

Token visual yang dipakai di seluruh website. Pakai ini untuk halaman baru agar konsisten.

## Colors

| Token | Hex | Usage |
|-------|-----|--------|
| Cream bg | `#FAF8F4` | Background utama |
| Soft cream | `#F0EBE3` | Panel sekunder, input area |
| Ink | `#1C1917` | Teks utama, CTA solid |
| Muted | `#6B6560` / `#6B5E52` | Body sekunder |
| Soft muted | `#9A8F82` | Placeholder, hint |
| Gold | `#C8B89A` | Accent subtle |
| Gold deep | `#B5935A` | Accent kuat, badge |
| White | `#FFFFFF` | Surface form / card |

### The Intimate tier accents

| Tier | Color |
|------|-------|
| Signature | `#8B7355` |
| Intimate | `#C9A96E` |
| Soulscent | `#B8860B` |
| Beloved | `#DAA520` |

## Typography

- **Display / heading:** `var(--font-cormorant)` — Cormorant Garamond (italic OK untuk hero)
- **Body / UI:** `var(--font-jost)` — Jost
- Label form: 10–11px, uppercase, letter-spacing ~2–3px, warna muted
- CTA: 10–12px, uppercase, letter-spacing ~2–3px

## Forms

- Input: tanpa border box; underline tipis `1px solid rgba(28,25,23,0.15)`
- Focus: underline `#1C1917`
- Background form: cream / white
- Submit: solid `#1C1917`, teks `#FAF8F4`

## Spacing

- Page horizontal padding: `8vw` (mobile `6vw` / `24px`)
- Section vertical: ~64–100px
- Form field gap: ~20–28px

## Auth split layout

- Desktop: 50/50 — kiri foto full-bleed, kanan form
- Mobile: foto di atas (min-height ~40vw) atau sembunyikan, form full width
